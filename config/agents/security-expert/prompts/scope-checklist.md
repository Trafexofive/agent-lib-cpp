# Scope checklist — confirm before ANY engagement work

1. Target(s) recorded in `ctx/engagement.md` under `scope:`.
2. Authorization: operator grant confirmed in-session or in the file. Record how.
3. Rules of engagement: passive-only or active allowed? Active = per-action asks.
4. Boundaries: exact asset list to touch; anything explicitly off-limits.
5. Findings ledger initialized (`ctx/findings.md`, id counter at F-000).
6. Open asks: anything the operator must decide before work can start.

Missing any item → `ask_tool` the operator for it before touching the target.
