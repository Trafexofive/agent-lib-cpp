# MK3 Skill Library

Skills are reusable operating policies for MK3 agents and workflows.
Only MK3-native skills live here — pi-agent-specific skills stay in `~/.pi/agent/`.

## Current set

| Skill | Purpose |
|-------|---------|
| `mk3-manifest` | Cortex-Prime MK3 module/manifest conventions |
| `harness-tuner` | Harness prompt compliance, protocol enforcement, regression testing |
